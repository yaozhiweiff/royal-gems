# 宫廷宝石 · Royal Gems

在线游玩：[宫廷宝石](https://yaozhiweiff.github.io/royal-gems/)。注册名字后即可开始，三个模式共用云端账号、各自独立排行。

支持注册和联网排行榜的网页三消游戏。采用用户提供的贝丝、兰斯、克丽丝、伊恩立绘与游戏内宝石素材，搭配石质宫廷背景、深绿色棋盘和旧金色边框。

## 启动

- 双击项目目录里的 **启动游戏.cmd**。启动器会启动本机账号服务并打开浏览器；游玩时保持服务窗口开启。需要 Node.js 24（本机已安装）。
- 开发：`npm ci`，分别运行 `npm run dev:api` 和 `npm run dev`，打开终端显示的本地地址。
- 重新生成可交付版本：`npm run build`。`dist/` 是静态站点，可部署到任何支持静态文件的站点根目录。
- 已构建版本的本地服务：`node scripts/serve.mjs --with-api`，默认地址 `http://127.0.0.1:4173`。

字体、角色、背景、宝石随网页提供；注册、开局、提交成绩及榜单需要连接后端。开局后交换、消除、连锁和角色技能均在本地即时计算，不逐步请求服务器；暂时断网也不阻塞操作。不要直接双击 `index.html`。GitHub Pages 与后端部署见 [DEPLOYMENT.md](DEPLOYMENT.md)。

首次游玩必须注册名字。名字经规范化后唯一，不区分大小写；同一个浏览器设备凭据只能绑定一个账号，返回时自动识别。凭据保存在浏览器存储，网页无法保证清除全部网站数据或换浏览器后的物理设备唯一性。整局完成后一次提交行动记录，后端重放计算榜单成绩，不接受客户端直接填报分数。

## 玩法

| 项目 | 规则 |
| --- | --- |
| 棋盘 | 8列 × 7行，5种普通宝石：红色三角、蓝色五边形、绿色方形、紫色圆形、黄色八角星 |
| 普通消除 | 相邻交换，横向或纵向3颗及以上同色消除，每颗实际清除的棋子10分 |
| 爆炸棋子 | 直线4连生成；参与消除时清除以自身为中心的3×3范围 |
| 十字棋子 | T形、L形5连及以上生成；参与消除时清除所在整行整列 |
| 终极棋子 | 直线5连及以上生成，使用彩色问号素材；交换普通棋子清除该颜色，两个终极交换清空棋盘 |
| 能量 | 每次有效交换50能量，每清除1颗额外2能量 |
| 角色技能 | 300能量自动释放第一技能，550能量自动释放第二技能并重置充能条 |
| 简单 | 20回合，2500分 |
| 困难 | 30回合，10000分 |
| 挑战 | 固定30回合，不设目标，回合结束后比较最终积分 |

鼠标拖动或依次点击相邻棋子；手机支持滑动及点选。双击特殊宝石（手机双点），或单击其右下角的放大镜，可查看该宝石的生成条件、触发方式和效果。爆炸、十字与彩色问号终极宝石均有查看符号。查看说明不改变棋盘、分数、回合或能量，关闭后继续对局。

两颗相邻特殊宝石交换即可触发组合，不要求同色或三连，只消耗一个回合。范围以交换落点为中心，超出棋盘的部分截断；命中的其他特殊宝石继续连锁，同一轮每颗宝石只计分一次。玩法指南与宝石详情均可查看组合规则。

三个模式各有联网排行榜，展示前十位注册玩家的名字、角色和个人最佳成绩。简单与困难按成功通关的实际行动次数升序；挑战按完成30回合后的积分降序；同成绩先达成者优先。每位玩家在每个模式只占一个位置，只在取得更好成绩时更新，失败和未完成的对局不入榜。原本的挑战本机前十名模块已移除。

排行榜入口旁和榜单弹窗内均显示当前模式的个人名次与距上一名的差距，即使未进前十也能查看。简单/困难以回合数比较，挑战以积分比较；无记录、榜首和同成绩均有独立提示。排名基于已提交的个人最佳成绩，切换模式、完成对局和打开榜单时刷新。

对局中点击“重来”保留进度重置确认；确认后回到难度、英雄选择界面，点击“开始挑战”才会创建新对局。

手机端（680px及以下）将角色选择和技能放在上方，棋盘放在下方并加宽。棋盘显示区为正方形，保留8列7行和原消除规则，按独立行高布置棋子及触控区域，宝石图案保持等比例。桌面端保留原比例；动画中旋转屏幕后，在动画结束时切换排布，避免点击与特效错位。

个人最佳随账号由服务端保存。简单和困难不计无效交换、自动连锁，伊恩增加剩余回合不会抵扣实际行动次数。挑战模式中伊恩的“从容布局”改为生成1颗爆炸宝石，确保全角色都严格使用30回合。

| 组合 | 效果 |
| --- | --- |
| 爆炸＋爆炸 | 清除5×5范围 |
| 爆炸＋十字 | 清除相邻3整行与3整列 |
| 十字＋十字 | 沿横、纵和两条对角线的八个方向清除至边缘 |
| 终极＋爆炸 | 全盘该颜色的非终极宝石先转为爆炸宝石，再全部引爆 |
| 终极＋十字 | 全盘该颜色的非终极宝石先转为十字宝石，再全部触发 |
| 终极＋终极 | 清空整个棋盘 |

键盘聚焦棋盘后，方向键移动、空格或回车选择交换；按I键查看当前特殊宝石。为避免双击第一下误触交换，特殊宝石的单击在约280毫秒后确认；拖动交换与查看按钮立即响应。

四位角色有不同的技能和玩法方向。角色在开局前选择，对局期间保持锁定；点击技能栏可以查看当前角色的两项技能。技能名称与角色台词为本原型的展示文案。

| 角色 | 300能量 | 550能量 |
| --- | --- | --- |
| 贝丝 · 转色连锁 | 宝石共鸣：随机直线5颗变为同色 | 王室敕令：最多与最少两色变为数量第三多的颜色 |
| 兰斯 · 横纵清场 | 纵横布局：2颗普通宝石升级为十字宝石 | 全局推演：清除相邻的两整行 |
| 克丽丝 · 范围爆破 | 绯红火花：2颗普通宝石升级为爆炸宝石 | 蔷薇盛放：清除一片5×5区域 |
| 伊恩 · 续航蓄势 | 从容布局：增加2个回合 | 王冠恩典：1颗普通宝石升级为彩色问号终极宝石 |

升级技能仅选择普通宝石，不覆盖已有特殊宝石。直接清除技能可以触发命中的特殊宝石，并按实际消除数量计分和充能。

消除表现按每轮实际清除数量分为四档：3–5颗为碎晶与轻光圈，6–11颗增加星芒，12–23颗增加扩散环，24颗以上呈现更密集的碎晶与全盘波纹。连锁次数、得分文字和音效同步反馈；爆炸宝石有范围冲击，十字宝石有横纵扫光，终极宝石有彩色连线。特效不会改变消除范围或计分。

默认使用完整特效与标准速度，依次表现聚能高亮、绽放消失和宝石下落。消除、生成、下落与技能等动画统一按原版的1.3倍速播放；默认单轮绽放持续369–654毫秒，下落约246毫秒。右上角“动画设置”可切换慢速/标准速度以及完整/柔和特效，手动保存的偏好会保留。系统“减少动态效果”不再改变首次进入的默认选择；柔和模式仍可手动选择，保留可见的高亮与淡出。

生成特殊宝石时，原宝石与匹配组一起完整播放消除，格子短暂留空后，再以凝聚光环和逐渐放大的效果生成新宝石，最后下落补齐。爆炸、十字、终极以及角色技能生成的特殊宝石均遵循此顺序；柔和模式使用高亮淡出与淡入。生成动作不额外增加计分、能量或回合消耗。

## 已补齐的实现约定

- 无效交换自动复原，不扣回合也不加能量；连锁下落不额外扣回合。
- 初盘无自动消除并保证有可行交换；无路可走时免费重排。
- 普通匹配保留一颗生成特殊棋子，优先放在交换落点；该保留棋子不计作已清除棋子。
- 同一消除结算内不重复计分；特殊棋子可以连锁触发其他特殊棋子；新生成的特殊棋子保留至下一轮。
- 直线5连与交叉形同时出现时，终极棋子优先。
- 角色转色保留爆炸/十字标记，不改动终极棋子。数量并列按固定颜色顺序（红、蓝、绿、紫、黄）排序。
- 终极棋子被其他特殊棋子炸到时，清除当前数量最多的一种颜色。
- 第二个技能释放时能量归零，技能造成的后续消除可为下一周期充能。
- 最后一回合在连锁与技能全部结算后判定胜负，达标优先判胜。
- 个人最佳和排行保存在后端；本机保存设备凭据、音效、动画偏好、所选角色及已完成但尚未上传的行动记录。提交失败可在结算页重试，也会在恢复网络或再次打开游戏后补传；服务器对局有效期为24小时。刷新会重新准备一局，未完成的中断对局不入榜。
- 原型未接入账号、服务器或正式游戏奖励系统。

## 结构与验证

- `src/engine.ts`：独立、可播种随机的三消规则与结算事件。
- `src/skills.ts`：四位角色的技能名称、能量阈值与效果说明。
- `src/combinations.ts`：特殊宝石组合类型、名称和规则说明。
- `src/scene.ts`：Phaser棋盘渲染、鼠标/触屏/键盘输入、动画。
- `src/motion.ts`：完整/柔和模式下慢速/标准速度的动画时长。
- `src/clear-effects.ts`：分级消除、特殊宝石特效与临时节点的生命周期管理。
- `src/main.ts`、`src/style.css`：注册、榜单、人物选择、界面、模态框和音效。
- `src/local-run.ts`：本地同步对局计算与完整行动记录。
- `src/online.ts`：设备凭据、账号、开局、整局提交、失败暂存与排行请求。
- `backend/api.ts`、`backend/migrations/`：服务端对局验证、唯一账号和榜单数据库。
- `backend/worker.ts`：Cloudflare Worker 入口；本地使用 `scripts/api-server.mjs` 与 SQLite。
- `public/assets/`：网页使用的本地素材。原始角色PNG仍保留在项目根目录。
- `npm test`：59项规则与后端测试，包括本地/服务端确定性一致、整局提交、无效与伪造成绩拒绝、幂等、三榜排序、手机坐标映射及原有技能和组合规则。
- `npm run test:latency`：断网时的桌面/触屏交换延迟、零逐步请求、特殊宝石点选反馈和双击查看、提交失败暂存、刷新保留与联网补传。
- `npm run test:mobile-layout`：320～680px布局、角色选择、实际触屏交换、最后一行特殊宝石查看、桌面比例和动画中旋转屏幕。
- `npm run test:ranking-restart`：启动独立测试服务，验证榜外排名、三榜差距、同成绩、榜首、手机布局和重来后重新选择角色/难度。
- `npm run test:online`：真实注册、重名拒绝、设备账号限制、完整30回合服务端对局、跨浏览器查看榜单和手机布局。默认使用独立测试前端 `http://127.0.0.1:5174`；可通过 `GAME_URL` 修改。
- `node scripts/production-smoke.mjs`：验证本机生产版本的注册、对局、暂停与规则入口，确认没有开发调试接口。
- 旧版 `test:browser`、`test:inspection`、`test:effects` 等脚本保留为离线版本历史测试夹具；在线版本入口有注册和服务端对局要求，应使用 `test:online`。
- 截图与浏览器报告在 `test-results/`。浏览器验收覆盖真实鼠标拖动、触屏点选、键盘、技能、胜负、重开和1920/1366/768/390/360宽度布局。

引擎文档参考：[Phaser 缩放](https://docs.phaser.io/phaser/concepts/scale-manager)、[Phaser 输入](https://docs.phaser.io/phaser/concepts/input)。字体为 [Noto Serif SC](https://fonts.google.com/noto/specimen/Noto+Serif+SC)，字库许可附于 `public/assets/fonts/OFL.txt`。
